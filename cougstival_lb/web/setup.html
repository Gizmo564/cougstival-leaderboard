3. Daily schedule

    
Each day's board counts points from open up to (not including) close. The scheduler always runs exactly at each close time.

    

      

      

      

      

    

    
    
NameOpensCloses

    
    
With "roll into the next day", each day opens when the previous one closes, so only the first day's open time is used.

  


  

    
4. Alerts (recommended)

    
Get a phone alert if the login breaks or updates stop. Install the free ntfy app, subscribe to a long random topic name, and enter it here. Optionally add a healthchecks.io ping URL, which alerts you if this computer goes silent.
